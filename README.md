Проект реализован в рамках тестового задания.

##  Запуск проекта

### 1. Клонирование репозитория

```bash
git clone https://github.com/Denver31/Test_assignment_Luna
cd Test_assignment_Luna
```
### 2. Создание .env файла
macOS:
```bash 
cp .env.example .env
```
Windows:
```bash 
copy .env.example .env
```
Или руками создать .env файл и записать туда данные из .env.example
### 3. Запуск через Docker
```bash
docker-compose up --build
```
Автоматически прогонятся миграции и запишутся тестовые данные
Документация доступна по адресу: http://localhost:8000/docs
### API KEY
Стандарное значение ключа: **api-key** \
Ключ настраивается через переменную окружения API_KEY в файле .env.

### Примечания
* Проект полностью асинхронный. Для работы используется asyncpg
* Ограничение на уровень вложенности реализовано только на стороне бизнес-логики
* Геопоиск реализован с использованием формулы Haversine, без PostGIS
* Используется модульная структура проекта
